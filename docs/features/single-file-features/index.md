# Single File Features

Single file features provide targeted operations for individual comic files. Accessible directly from the <i class="bi bi-three-dots-vertical fs-2 text-icon"></i> action menu across the **Collection**, **File Manager**, and **Source Wall** views, these tools let you inspect, repair, crop, or enhance specific issues without running batch jobs across entire directories.

## Available Single File Features

| Feature | Description | Documentation |
| --- | --- | --- |
| **Edit CBZ File** | Visually reorder pages, upload replacement covers, crop artwork, and remove junk files. | [Edit CBZ File](edit.md) |
| **Single File Rebuild** | Repair corrupted archive headers and convert individual CBR or RAR files to CBZ. | [Single File Rebuild](rebuild.md) |
| **Crop Cover** | Automatically split a wraparound cover, isolating the front cover as the primary image. | [Crop Cover](crop.md) |
| **Remove First Image** | Delete unwanted lead pages, scanner watermark cards, or advertisement splash screens. | [Remove First Image](remove.md) |
| **Add Blank Image** | Append a trailing blank image to fix two-page spread alignment in manga readers. | [Add Blank Image](add.md) |
| **Enhance Images** | Apply automated contrast and curve adjustments across all pages in a single issue. | [Enhance Images](enhance.md) |
| **Add Read Date** | Manually log or update the date an issue was read to enrich reading statistics. | [Add Read Date](date.md) |
| **Delete File** | Remove a single issue from disk, with soft-delete recovery via the Trash Can. | [Delete File](delete.md) |
